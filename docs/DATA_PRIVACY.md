# Privacidad y consentimiento

Un activo no sale de la PC sin consentimiento explícito registrado. La UI muestra activo, proveedor, propósito y estimación. Rechazar el envío mantiene el flujo local y marca información faltante en vez de inventarla.

El MCP no expone shell, rutas arbitrarias, aplicaciones personales ni lectura fuera de la raíz del proyecto.
